## 簡易的な fetch-wrapper

### 作成理由
* マインドリフレッシュのために超小規模のパッケージを作成する
* Zod系のOSSを眺めていた時に、抽象的な型の扱いについて知らないことが多かった
* 普段使うコードの抽象化を通して共通点を見いだすことが出来るかもしれないと考えた
* 既存ライブラリの一機能をイメージすることで効率的に学習できるかもしれない

### 学習レポート（制作過程の感想や気づき）
* **npm workspace**を利用した理由
  * 小さな機能をパッケージ化するだけであれば workspace があれば十分に管理しやすい
  * 循環参照や学習コストがデメリットに挙げられるが、よほど構造が不明瞭なプロジェクトでなければ、どちらも問題にならないと判断した
* AI利用の課題について
  [AIによる推奨とそのリスク](./docs/AI.md)
  ↑学習の本筋から外れますが、個人的に印象が強かったのでまとめています
